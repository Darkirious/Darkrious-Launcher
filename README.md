## 🇬🇧 English

### 📖 About

Darkrious Launcher is a custom Minecraft launcher designed to provide a simple, modern and customizable way to manage and launch Minecraft.

The launcher includes features such as Minecraft version selection, installation, mod support, modpack creation, RAM configuration and player settings.

### ✨ Features

- 🎮 Minecraft version selection
- ▶️ Launch Minecraft
- 📥 Minecraft installation
- 🔨 Forge / Fabric support
- 📦 Modpack creation
- 🧩 Mod management
- ✨ OptiFine support
- 💾 RAM configuration
- 👤 Player name configuration
- 🎨 Custom interface
- ⚙️ Settings
- 🌙 Dark-themed interface
- 🖼️ Minecraft-style background

### 🖥️ Requirements

- Windows
- Python 3.x
- Java Runtime Environment (JRE/JDK) for Minecraft
- Internet connection for downloading Minecraft files and dependencies
